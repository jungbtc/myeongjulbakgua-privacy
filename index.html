명절백과 개인정보 처리방침

촌수부터 호칭까지 한 번에

1. 수집하는 개인정보

명절백과는 이용자의 개인정보를 수집, 저장 또는 외부로 전송하지 않습니다. 회원가입과 로그인이 없습니다.

2. 가족 관계 정보

호칭을 찾기 위해 선택한 가족 관계는 기기 안에서만 처리됩니다. 앱은 이 정보를 서버로 보내거나 영구적으로 저장하지 않습니다.

3. 제3자 서비스

앱에는 광고, 이용 분석, 추적 도구, 타사 로그인 및 인앱결제가 포함되어 있지 않습니다.

4. 기기 기능 사용

인사말 복사 기능은 이용자가 선택한 문구를 기기의 클립보드에 저장합니다. 결과 공유 기능은 iOS 공유 시트를 사용하며, 이용자가 직접 공유 대상을 선택합니다.

5. 어린이의 개인정보

앱은 어린이를 포함한 어떤 이용자의 개인정보도 수집하지 않습니다.

6. 변경

앱의 기능이나 정보 처리 방식이 바뀌는 경우 이 페이지를 갱신합니다.

7. 문의

개인정보 처리방침에 대한 문의는 GitHub Issues를 이용해 주세요.
